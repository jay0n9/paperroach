The individual dynamics of affective expression on social media

TL;DR

This paper tests a computational model of affective dynamics using Facebook status updates. Text-derived valence and arousal return exponentially toward an individual-specific baseline, while expression is associated with an immediate proportional movement toward that baseline.

Model

E[xᵢ(t+Δt)] = e−γΔt(xᵢ(t)−μᵢ)+μᵢ

Reported fit

kᵥ = 0.38kₐ = 0.45γᵥ = 0.0070 s⁻¹γₐ = 0.0105 s⁻¹

Review boundary

The reviewed note describes text-derived affective expression and avoids turning an observational coefficient into a causal or clinical claim.

What review changed

  • Corrected the Computer Vision misclassification.
  • Restored γₐ, kₐ, and εₐ in the arousal equation.
  • Separated per-user baselines from pooled model fitting.
  • Added observational, sampling, and prediction limits.

C-02Exponential Relaxation+

Source evidence — Arousal relaxed faster than valence in the fitted model.

Source evidence — Aggregate means were 5.88 for valence and 4.13 for arousal on 1–9 scales.
