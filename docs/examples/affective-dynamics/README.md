# PaperRoach public case study

This folder contains a complete, inspectable PaperRoach example built from a copyright-cleared research paper.

## What is included

- `original/pellert-et-al-2020.pdf` — unchanged 14-page source PDF.
- `processed/paper-note.generated.md` — actual machine output with local path and internal ID redacted.
- `processed/paper-note.md` — source-checked public review copy.
- `derivatives/*.generated.md` — four actual generated concept drafts.
- `derivatives/*.md` — four source-checked concept notes.
- `manifest.json` and `SHA256SUMS.txt` — machine-readable provenance and checksums.
- `ATTRIBUTION.md` — source, license, and adaptation notice.
- `CHANGELOG.md` — every public-review correction.

The generated drafts are published for transparency and are not source-verified. The reviewed files are the default reading copies. Open `index.html` on the published site for the visual walkthrough.

## Data not included

The study's underlying Facebook/MyPersonality dataset is not part of this bundle. Only the article PDF and notes derived from the article are included.
